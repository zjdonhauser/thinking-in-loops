# Thinking in Loops

Turn repeatable work into self-improving skill loops. When a task is a *known shape* you'll do many times, stop hand-prompting it — design a loop that runs the agent end to end and sharpens itself every run. The shift is from **prompt engineering** to **loop engineering**.

**[View the presentation →](https://zjdonhauser.github.io/thinking-in-loops/)**

## What's inside

1. **The paradigm** — from prompting agents to writing loops (Boris Cherny, Peter Steinberger).
2. **The shift** — prompt engineering → loop engineering.
3. **What makes a loop self-improving** — the retrospective that compounds, so run N+1 beats run N.
4. **When to reach for a loop** (and when not).
5. **Worked example** — the `/add-new-doctype` skill: its 12 phases (hover to explore) and a week of real runs.
6. **Keep the spine general** — one loop, a family of adjacent tasks.
7. **The playbook** — six steps for building your own.

Built by reusing the format and engine from [agentic-engineering](https://github.com/zjdonhauser/agentic-engineering).

## Running locally

Open `index.html` in a browser. Arrow keys / space to navigate, hover the phase chips for detail. No dependencies.
